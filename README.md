# CyberShield

CyberShield is an authorized website security assessment platform that performs automated, non-destructive checks for HTTPS availability, TLS certificate status, and selected HTTP security headers.

It provides risk analysis, security findings, remediation recommendations, assessment reports, notifications, and assessment history.

## Features

- User authentication and role-based access control
- Separate Client, Security Analyst, and Administrator dashboards
- Website registration and authorization confirmation
- HTTPS availability checks
- TLS certificate status checks
- HTTP security header checks
- Risk scoring and severity classification
- Findings and remediation recommendations
- Assessment history and reports
- Notifications and incident management

## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- PostgreSQL
- Neon
- Prisma ORM
- Node.js

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Configure your environment variables in a `.env` file. Do not upload this file to GitHub.

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see CyberShield.

## Project Scope

CyberShield is designed for authorized, basic, and non-destructive website security assessments. It does not perform penetration testing, exploitation, or comprehensive vulnerability scanning.
